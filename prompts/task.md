Создай задание по этикету для детей 7-10 лет. Задание содержит только один вопрос.
Формат задания должен быть следующим:
1) Ситуация;
2) 3-4 вариантов ответа (1 из должен быть шуточный, 1 из них правильный-вежливый)
3) Объяснение, которое должна начинаться со слов "Правильный ответ"
Перепроверь себя - среди вариантов должен быть обязательно правильный ответ.
Объяснение должно быть лаконичным, понятным детям и достаточно кратким.
